# Fluxo de Git

```text
Issue / Task
    ↓
Branch
    ↓
Implementação
    ↓
Teste local
    ↓
Commit
    ↓
Push
    ↓
Pull Request
    ↓
Code Review
    ↓
Ajustes
    ↓
Merge
```

## Branches

Use nomes curtos que expressem o objetivo:

- `feat/*`
- `fix/*`
- `refactor/*`
- `docs/*`
- `training/*`

## Commits

Prefira commits pequenos e coerentes. Prefixos sugeridos:

- `feat:`
- `fix:`
- `docs:`
- `refactor:`
- `test:`
- `chore:`

Antes do push, atualize a branch quando necessário, execute as validações locais e confira o diff que será enviado.
