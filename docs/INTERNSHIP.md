# Orientações do estágio

Cada tarefa deve ser desenvolvida em uma branch própria. Antes de alterar o código, leia o contexto, reproduza o problema e formule uma hipótese. Mantenha as mudanças dentro do escopo da tarefa e teste o resultado antes de abrir o Pull Request.

Na descrição do PR, resuma a solução, explique as decisões técnicas e registre como o comportamento foi validado. Leia o code review, responda às observações e faça os ajustes necessários em novos commits coerentes.

Ferramentas de IA podem ser usadas como apoio somente quando houver autorização do supervisor. Todo código entregue deve ser compreendido e explicado pela própria autora.
