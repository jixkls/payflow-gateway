# Task 04 — Processamento de transações

Implemente funções que:

1. retornem somente transações `PAID`;
2. retornem os IDs das transações `PAID`;
3. calculem o valor total das transações `PAID`;
4. encontrem uma transação pelo ID;
5. retornem somente transações pagas que possuem email de cliente.

Escolha os métodos de array adequados e explique brevemente suas escolhas.
