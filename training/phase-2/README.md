# Fase 2 — Backend + Banco aplicado

Nesta fase, as tarefas representam features e problemas de backend próximos de situações reais.

Fluxo esperado:

1. escolher a task atual;
2. atualizar a `main`;
3. criar branch própria;
4. entender o requisito;
5. propor decisões quando necessário;
6. implementar;
7. testar;
8. abrir Pull Request;
9. responder ao review;
10. realizar ajustes;
11. mergear somente após aprovação.

As tasks devem ser executadas em ordem:

Task 09
→ Task 10
→ Task 11
→ Task 12

Não iniciar a próxima antes do merge da anterior, pois as etapas seguintes dependem do código produzido anteriormente.
