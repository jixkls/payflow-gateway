# Task 01 — Git Conflict

Atualize sua branch com a versão mais recente da `main`.

Existe um conflito de merge proposital.

Resolva o conflito preservando os dois comportamentos existentes.

## Critério de aceite

- projeto compila;
- nenhum comportamento é perdido;
- marcadores de conflito não permanecem no código;
- commit final explica a resolução.
