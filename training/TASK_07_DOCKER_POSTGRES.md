# Task 07 — PostgreSQL com Docker

Configure e execute o PostgreSQL do projeto usando Docker.

## Requisitos

- banco deve persistir dados;
- credenciais devem vir de variáveis de ambiente;
- aplicação deve conseguir conectar ao banco;
- criar uma migration;
- criar registros de exemplo;
- executar uma consulta simples para validar os dados.

## Entrega

Inclua no PR os comandos utilizados para validar o funcionamento.
